## Facebook

### Post

團隊討論用網頁連接公司現有的 Bluetooth 裝置時，第一個問題通常是：「JavaScript 能不能做到？」

Web Bluetooth 確實提供了連接 Bluetooth Low Energy 裝置的方式，但我更在意的不是 API 有沒有，而是它能不能在公司的真實環境裡完成工作。

目標瀏覽器與裝置的支援、Secure Context、使用者選擇與授權，都會直接影響產品流程。連按鈕放在哪裡、現場人員看不看得懂提示、斷線後怎麼繼續，都要一起驗證。

所以我的評估方式不是讀完文件就決定採用，而是先做一個小型 PoC。用預計支援的瀏覽器、作業系統與實際裝置，逐一測試連線、資料讀取、斷線重連和權限流程，再決定是否進入正式產品。

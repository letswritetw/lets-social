# Telegram

Use this reference only when generating or revising Telegram content.

## Native goal

Deliver a clear, information-dense channel message that readers can scan and act on.

## Decisions

1. Use a short, factual title when it improves scanning.
2. State what the article covers and why it is useful with minimal emotional setup.
3. Use bullets for distinct takeaways, checks, or steps when they improve clarity.
4. Place the source URL where the reader can act on it when a URL is available.
5. Vary the structure to match the source. Do not force every article into one announcement template.

Keep marketing pressure low. Information density can be higher than Instagram or Threads, but the message should not reproduce the article.

## Default fields

- `Message`
- `Link Placement Recommendation`

If no URL was provided, say where to add it rather than inventing one.

## Pre-flight

- A reader can identify the article's value in one scan.
- Bullets are parallel, specific, and source-grounded.
- The message avoids excessive emotional framing.
- The link recommendation reflects whether a real URL is available.

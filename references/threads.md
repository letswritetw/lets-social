# Threads

Use this reference only when generating or revising Threads content. Read [image prompts](image-prompts.md) only when media materially supports the selected angle or the user requests it.

## Native goal

Sound like a person sharing an observation, discovery, or working conclusion that others can respond to.

## Decisions

1. Open with the point, question, or observation. Skip formal introductions.
2. Prefer short sentences, conversational language, and deliberate line breaks.
3. Select one strong angle instead of packing in every source point.
4. Leave room for discussion without manufacturing controversy.
5. Use only a supplied or confirmed source URL. For a single post, place it after the main point when direct traffic is part of the user's goal. For a thread, place it in the final entry unless the user requests another location.
6. Choose a single post by default. Use a thread only when a sequence materially improves comprehension.
7. Add image direction and copy-ready prompts only when a visual clarifies a comparison, process, physical subject, spatial relationship, or source-grounded concept. A decorative image does not justify the fields.

Avoid corporate voice, press-release language, and hashtag stacks. Omit hashtags unless the user asks for them or one specific tag has a clear purpose.

## When a thread is justified

Use a thread for a source-grounded sequence such as steps, trade-offs, or a developing argument that cannot stay clear as one post. Split each entry cleanly and label the order. Do not create a thread only because the source is long.

## Default fields

- `Post`
- `Thread`, only when justified; omit `Post` when the thread is the selected form
- `Image Direction`, only when justified
- `Nano Banana 2 Prompt`, only when justified
- `ChatGPT Images 2.5 Prompt`, only when justified

## Pre-flight

- The first line contains a real point, not a promotional announcement.
- The voice is conversational without becoming vague.
- The post differs from Facebook in angle, structure, and rhythm.
- Any question can prompt a meaningful reply.
- Any link is confirmed and placed without interrupting the opening point.
- When image fields appear, the visual gives the selected observation a clear, source-grounded form.
- When media adds no clear value, all image fields are absent.
